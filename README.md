# VLSI Projects

This repository contains all my digital design and verification projects, ranging from basic combinational logic to complex RTL systems. built progressively from Year 1 through Year 4 as part of my path toward semiconductor engineering roles.

Each project includes synthesizable RTL code and a self-checking testbench and every project is implemented in Verilog or SystemVerilog,
simulated using EDA Playground or Xilinx Vivado, and
documented with simulation output and waveform screenshots.
