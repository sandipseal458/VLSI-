# Intermediate Projects

Real serial protocols and datapath components, each with a self-checking
testbench (Icarus Verilog, `iverilog` / `vvp`) and its simulation log.

| # | Project | Skill |
|---|---------|-------|
| P07 | [SPI Master & Slave](./P07-spi-master-slave/) | SPI full-duplex byte exchange, Mode 0 timing |
| P08 | [I2C Master & Slave](./P08-i2c-master-slave/) | I²C open-drain bus, address decode, ACK/NACK |
| P09 | [UART Transceiver](./P09-uart-transceiver/) | 8N1 framing, 16× oversampling receiver |
| P10 | [32 × 32 Register File](./P10-register-file/) | 1 write / 2 read ports, processor datapath |
